# Mi Home Toolkit v1.6.0

## 更新内容

### 挂灯控制

- 修复背景灯偶发无法开启的问题：之前 Hue / Saturation 调整会把背景灯切换到 HSV 模式，
  该模式在「关闭后再开启」时可能让背景灯通道失去响应（命令返回成功但灯不亮，只能断电复位）。
  本版统一改用以 RGB 下发颜色，不再进入 HSV 模式。
- 主灯与背景灯状态现在分别解析：只开背景灯时，主灯不再被误显示为开启。
- 背景灯关闭时，`bg_rgb` 返回空值也能正确回退，不再出现读取状态后颜色控件跳变。
- 所有亮度、色温、Hue、Saturation 控制条支持鼠标滚轮微调：悬停后滚轮上下各走一档，
  停止滚动后自动合并为一次命令。
- 电源开关增加 1 秒操作间隔：主灯、背景灯、整体开关在命令发出后短暂禁用，
  避免快速连点导致设备状态机异常。
- 灯处于关闭状态时，会自动禁用该灯对应的亮度、色温、颜色等设置，避免无效操作。
- 饱和度为 0（纯白）时，Hue 滑块会禁用并给出提示，不再出现「拖了色相但颜色不变」的困惑。
- 修复灯光命令队列的竞态问题：状态回读期间提交的新命令不会再滞留，滑块与设备状态保持一致。

### 其他

- 窗口标题现在显示版本号（`Mi Home Toolkit v1.6.0`），随版本发布自动更新。
- 设备命令调用会记录 method、参数与返回结果到日志，便于排查设备交互问题。

## 运行要求

- Windows 10 1803 及以上，或 Windows 11
- 需要 WebView2 运行时（Win11 与大部分 Win10 已内置；缺失时安装 [Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)）

## 使用方法

1. 下载 `MiHomeToolkit-<版本>-windows-x64.exe`，放到任意目录
2. 双击运行，无需安装、无需解压
3. 使用小米账号登录；首次登录可能需要进行验证码或二次验证
4. 在设备列表中，`yeelink.light.lamp15` 设备卡片上会显示灯光控制按钮

程序本身是免安装的，但用户数据不会随文件夹移动：

- 登录会话：`%APPDATA%\com.mi-home-toolkit\session.json`
- 记住的账号密码：Windows 凭据管理器中的 `com.mi-home-toolkit` 条目

## 已知限制

- 本版本仅提供 Windows x64 便携版，未提供安装程序
- 程序未做代码签名，首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，
  请点击「更多信息 → 仍要运行」
- 登录会话在小米服务端失效后需要重新登录，这是小米云凭证机制的限制
- 同一账号短时间内反复进行完整登录可能触发小米风控，请避免频繁退出后立即重登
- 若背景灯因旧版本行为已进入无响应状态，仍需断电复位：拔插电源适配器并连续开关灯 5 次
  （每次开、关约 2 秒），灯出现呼吸效果后即可恢复
